# @oracle/geo

База городов для поля «Место рождения» натальной карты и поиск по ней (`GET /api/cities`).

## Источник и лицензия

Данные — [GeoNames](https://www.geonames.org), дампы с <https://download.geonames.org/export/dump/>.
Лицензия [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0): нужно указывать источник.

Фраза для страницы «Методика»: «Список городов и их координаты, часовые пояса и русские названия — по данным GeoNames (geonames.org), лицензия CC BY 4.0».

Дата загрузки: **2026-10-15**.

## Файлы дампа (лежат вне репозитория, в `C:\dev\geonames\`, в git не попадают)

| Файл | Зачем |
|---|---|
| `cities5000/cities5000.txt` | места от 5000 жителей по всему миру (69 806 записей) |
| `cities1000/cities1000.txt` | места от 1000 жителей; берутся только для стран из `FULL_COVERAGE_COUNTRIES` (171 264 записи в файле) |
| `alt-world/alternateNamesV2.txt` | альтернативные названия всех объектов мира (из `alternateNamesV2.zip`, 195 МБ, загружен 2026-10-15; распакованный файл около 786 МБ, читается потоком) — источник русских названий |
| `alt-RU/RU.txt`, `alt-BY/BY.txt`, `alt-KZ/KZ.txt`, `alt-UA/UA.txt` | запасной источник русских названий, если `alt-world` нет |
| `admin1CodesASCII.txt` | названия регионов (`CC.admin1` → название и `geonameid`) |

## Сборка

```bash
node packages/geo/scripts/build-cities.mjs C:\dev\geonames
```

Скрипт читает файлы потоком, детерминирован (одинаковый вход — побайтно одинаковый `data/cities.json`) и печатает статистику: число мест, по группам (RU/BY/KZ/UA, остальной бывший СССР, остальной мир) сколько с русским названием и сколько с названием GeoNames, сколько регионов с русским названием, сколько отброшено из-за пустого часового пояса, размер файла. Полная сборка занимает около 20 секунд.

Сборка строгая (в том числе для каждой строки `alternateNamesV2.txt`: ровно 10 колонок): строка дампа с неверным числом колонок или нечисловыми id, широтой, долготой и населением останавливает её с кодом 1 и сообщением `файл:строка` (файл не пишется); если городов получилось меньше 60 000, дамп считается обрезанным и сборка тоже падает. Необязательные параметры: `--out <файл>` и `--min-cities <число>` (для тестов).

Правила сборки:

- Набор мест: всё из `cities5000` плюс места из `cities1000` в странах из константы `FULL_COVERAGE_COUNTRIES` в `scripts/build-cities.mjs` — RU, BY, KZ, UA, UZ, TJ, KG, TM, AZ, AM, GE, MD, LV, LT, EE, то есть Россия и бывший СССР (объединение по `geonameid`, без дублей). Строки с пустым часовым поясом отбрасываются с предупреждением.
- Названия, основной режим: если есть `alt-world/alternateNamesV2.txt`, он единственный источник русских названий для всех мест и регионов. Скрипт сначала собирает нужные `geonameid` (места и их регионы), затем читает большой файл один раз потоком и оставляет только строки с этими id. Среди записей с языком `ru` и без признака «историческое» предпочитается `isPreferredName`, иначе первая; если русского нет — название GeoNames (латиницей) или название региона из `admin1CodesASCII.txt`. Знак ударения (U+0301) убирается: он ломает поиск по началу слова.
- Названия, запасной режим: если папки `alt-world` нет, русские названия берутся тем же правилом, но только для RU, BY, KZ, UA — из `alt-RU`, `alt-BY`, `alt-KZ`, `alt-UA`; остальной мир остаётся латиницей.
- Регион: русское название региона (тем же правилом, для всех стран в основном режиме и для RU/BY/KZ/UA в запасном), иначе название из `admin1CodesASCII.txt`; если региона нет — пустая строка.
- Страна: `new Intl.DisplayNames(["ru"], { type: "region" }).of(код)`.
- Порядок: по убыванию населения, при равенстве — по `geonameid`.

## Формат `data/cities.json`

Объект на город не уложился бы в бюджет размера (в тесте лимит файла — 6 МБ), поэтому файл компактный:

```json
{ "zones": ["Asia/Shanghai", "..."], "countries": ["Китай", "..."], "regions": ["Shanghai", "..."],
  "rows": [[id, "название", индекс региона, индекс страны, широта, долгота, индекс зоны, население], "..."] }
```

Координаты округлены до 4 знаков. `src/index.ts` один раз при загрузке разворачивает файл в публичный `CITIES: readonly City[]`.

## Ограничения

Русское название есть не у каждого места: у части малых городов мира в GeoNames нет записи с языком `ru`, и тогда показывается название GeoNames латиницей (число таких мест печатает сборка). Русские названия берутся из данных GeoNames как есть (без правки вручную), поэтому в отдельных случаях написание может отличаться от привычного. Места от 1000 до 5000 жителей есть только в России и странах бывшего СССР; в остальном мире — от 5000.
