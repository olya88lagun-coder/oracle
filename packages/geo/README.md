# @oracle/geo

База городов для поля «Место рождения» натальной карты и поиск по ней (`GET /api/cities`).

## Источник и лицензия

Данные — [GeoNames](https://www.geonames.org), дампы с <https://download.geonames.org/export/dump/>.
Лицензия [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0): нужно указывать источник.

Фраза для страницы «Методика»: «Список городов и их координаты, часовые пояса и русские названия — по данным GeoNames (geonames.org), лицензия CC BY 4.0».

Дата загрузки: **2026-10-15**.

## Файлы дампа (лежат вне репозитория, в `C:\dev\geonames\`, в git не попадают)

| Файл | Зачем |
|---|---|
| `cities5000/cities5000.txt` | места от 5000 жителей по всему миру (69 806 записей) |
| `cities1000/cities1000.txt` | места от 1000 жителей; берутся только для RU, BY, KZ, UA (171 264 записи в файле) |
| `alt-RU/RU.txt`, `alt-BY/BY.txt`, `alt-KZ/KZ.txt`, `alt-UA/UA.txt` | альтернативные названия объектов этих стран (для русских названий городов и областей) |
| `admin1CodesASCII.txt` | названия регионов (`CC.admin1` → название и `geonameid`) |

Полный `alternateNamesV2.zip` не используется: он весит около 195 МБ.

## Сборка

```bash
node packages/geo/scripts/build-cities.mjs C:\dev\geonames
```

Скрипт читает файлы потоком, детерминирован (одинаковый вход — побайтно одинаковый `data/cities.json`) и печатает статистику: число городов, сколько без русского названия, сколько отброшено из-за пустого часового пояса.

Правила сборки:

- Набор мест: всё из `cities5000` плюс места из `cities1000` в RU, BY, KZ, UA (объединение по `geonameid`, без дублей). Строки с пустым часовым поясом отбрасываются с предупреждением.
- Названия: русское название — только для RU, BY, KZ, UA, из соответствующего файла `alt-*`: среди записей с языком `ru` и без признака «историческое» предпочитается `isPreferredName`, иначе первая; если русского нет — название GeoNames. Знак ударения (U+0301) убирается: он ломает поиск по началу слова. Для остальных стран — название GeoNames (латиницей).
- Регион: для RU/BY/KZ/UA — русское название региона (тем же правилом), иначе название из `admin1CodesASCII.txt`; если региона нет — пустая строка.
- Страна: `new Intl.DisplayNames(["ru"], { type: "region" }).of(код)`.
- Порядок: по убыванию населения, при равенстве — по `geonameid`.

## Формат `data/cities.json`

Объект на город не уложился бы в бюджет размера (в тесте лимит файла — 6 МБ), поэтому файл компактный:

```json
{ "zones": ["Asia/Shanghai", "..."], "countries": ["Китай", "..."], "regions": ["Shanghai", "..."],
  "rows": [[id, "название", индекс региона, индекс страны, широта, долгота, индекс зоны, население], "..."] }
```

Координаты округлены до 4 знаков. `src/index.ts` один раз при загрузке разворачивает файл в публичный `CITIES: readonly City[]`.

## Ограничения и возможное улучшение

Русские названия есть только у городов RU/BY/KZ/UA; остальной мир показывается латиницей. Чтобы дать русские названия всем странам, понадобится полный `alternateNamesV2.zip` (≈ 195 МБ) — это отдельное улучшение на будущее.
