# «Твой оракул» — правила для агентов

Сайт символических практик для самопознания: https://tvoy-orakul.ru. Монорепозиторий pnpm (Node 24): Next.js 16 (App Router) в `apps/web`, общие пакеты в `packages/`. Внутреннее имя проекта `oracle` остаётся в путях, базе и образах — не переименовывать.

## Визуальный дизайн (Codex)

Задача — визуальное обновление главной и личного кабинета («Мой портрет») поверх текущего `master`, а не переписывание сайта. Работать в отдельной ветке от свежего `master`, сдавать pull request'ом.

### Должно остаться на месте

По этому проверяют автотесты (`e2e/`) и проверка после выкладки (`.github/workflows/deploy.yml`):

- **Тексты кнопок, ссылок и полей — дословно:** «Войти через VK ID», «Открыть портрет», «Сохранить», «Выйти», «Удалить мои данные», «Удалить навсегда», поле с подписью «Дата рождения», в подвале «Политика обработки данных» и кнопка «Настройки cookie», в cookie-баннере «Только необходимые», метка «Скоро» на карточках практик; на калькуляторе матрицы — поле «Дата рождения», кнопки «Рассчитать», «Войти и сохранить», «Сохранить в портрет», «Повторить», «Поделиться», «Рассчитать свою матрицу», отметка «Сохранено.»; метки практик «Открыто»/«Скоро»; на главной кнопка «Рассчитать матрицу бесплатно»; платный разбор — заголовок блока «Разбор всей матрицы — 390 ₽», кнопки «Войти и купить разбор», «Купить разбор — 390 ₽», «Открыть разбор», на странице разбора «Скачать PDF», «Попробовать снова», поле «E-mail для чека», в подвале ссылка «Оферта».
- **Лила — тексты и роли дословно:** «Играть», «Бросить кубик», «Играю со своим кубиком», «Сохранить партию», «Продолжить партию», «Завершить партию», «Играть без проводника», «Войти и сохранить партию», «Сохранить» и отметка «Сохранено.» у записи мысли, подпись «Открыто клеток»; на странице клетки — заголовки «Вопросы для размышления» и «Змея»/«Стрела»; на `/lila` и `/lila/igra` ровно один `<h1>`; статус хода — `role="status"`, ошибки — `role="alert"`; партия и намерение гостя не уходят на сервер, пока он не нажал «Сохранить партию».
- **Лила, платное — тексты и роли дословно:** «Начать с проводником — 490 ₽», «Войти и начать с проводником», «Играть без проводника», «E-mail для чека», «Попробовать снова», «Скачать PDF» (итог партии), «Завершить партию»; статусы «Проводник пишет…» и «Готовим итог» — `role="status"`, «Оплата не прошла» — `role="alert"`.
- **Совместимость — тексты и роли дословно:** `<h1>` «Совместимость по дате рождения» (один на странице); поля «Ваша дата рождения», «Дата рождения партнёра»; кнопки «Рассчитать совместимость», «Отправить партнёру», «Скачать PDF», «Пересчитать»; отметка «Ссылка скопирована.» — `role="status"`, ошибки — `role="alert"`; блоки результата «Аркан вашей пары», «Вы и партнёр», «Где вы похожи и где различаетесь»; даты не попадают в адрес страницы и в хранилище браузера, на сервер уходят только запросом «Скачать PDF» и там не сохраняются и не логируются; ссылка приглашения общая и без дат. Метки практик: «Открыто» — матрица, Лила, совместимость, таро; «Скоро» — натальная карта.
- **Таро — тексты и роли дословно:** `<h1>` «Таро и карта дня» на `/taro` и «Карта дня» на `/taro/karta-dnya` (по одному на странице); ссылка «Вытянуть карту дня» на `/taro`; на странице карты дня подпись «Выберите одну из трёх карт.» и три кнопки-рубашки «Карта 1», «Карта 2», «Карта 3» (карта под любой из них выбирается случайно из всей колоды), кнопки «Поделиться картой», «Значение карты»; отметки «Ваша карта дня уже вытянута.» и «Ссылка скопирована.» — `role="status"`; заголовки разделов страницы карты дословно из `TAROT_SECTION_TITLES` («Суть», «В отношениях», «В деле и деньгах», «Ресурс», «Перекос», «Как карта дня», «Действие на сегодня», «Вопрос для себя»); авторство «Рисунки Памелы Колман Смит, 1909 (общественное достояние)»; на карточке практики «Таро» кнопка «Вытянуть карту»; выбор карты и запись `taro:day:v1` (только сутки и слаг карты) остаются в браузере, на сервер не уходят.
- **Роли:** cookie-баннер — `role="dialog"` с `aria-label="Cookie"`; сообщение после сохранения даты — `role="status"`, ошибки — `role="alert"`; ровно один `<h1>` на странице; подвал — элемент `<footer>`; результат матрицы — `<section aria-labelledby>` с заголовком «Ваша матрица судьбы»; у ключевых арканов в `<h3>` скрытый префикс «Аркан N, ».
- **Метаданные страниц** (`export const metadata`, `publicMetadata`): заголовок главной «Твой оракул — символические практики для самопознания», canonical-ссылки, `noindex` на `/portret` и `/login`.
- **Дисклеймер** о том, что практики — инструмент самопознания, а не предсказание и не консультация (`DISCLAIMER` в подвале).
- **Счётчик Яндекс.Метрики** подключается только после согласия в cookie-баннере — логику `Analytics.tsx` не менять.

### Ограничения

- Внешние CDN, шрифты и скрипты со сторонних доменов не подключать: всё отдаётся с нашего домена (152-ФЗ, политика перечисляет всех получателей данных).
- Мобильные в приоритете: на ширине 375 px не должно быть горизонтальной прокрутки, текст не мельче 14 px, зоны нажатия не меньше 44 px.
- Контраст текста — не ниже WCAG AA; фокус с клавиатуры виден.
- Анимации — с `@media (prefers-reduced-motion: reduce)`.

## Проверки перед сдачей

```bash
pnpm install
pnpm typecheck
pnpm test
```

Локальный запуск для просмотра: скопировать `apps/web/.env.development.example` в `apps/web/.env.development.local`, затем в одном терминале `pnpm dev:db`, в другом `pnpm dev:web` → http://localhost:3000. Вход без VK — открыть http://localhost:3000/api/dev/login?name=Тест (работает только локально, с `DEV_LOGIN=1`), после него откроется портрет.

Сквозные тесты (нужен установленный Chrome и запущенные `dev:db`, `dev:web` и `dev:worker`; в `.env.development.local` — `PAYMENTS=fake`, `PAID_REPORTS=on` и `PAID_LILA=on`, как в примере):

```bash
pnpm test:e2e
```

## Прочее

- Тексты сайта — на русском, обращение на «вы», без обещаний предсказать будущее.
- Коммиты — conventional commits на английском (`feat(web): …`, `style(web): …`).
- Мерж в `master` сразу выкладывает сайт — мержит только владелица после проверки.
