# Дни недели — объёмные планеты

Владелица выбрала объёмные планеты с бронзовым светом вместо гравированных медальонов. Это новый проход только по `/dni-nedeli`, поверх #292.

Семь отдельных прозрачных изображений заменяют векторные знаки в сцене, ленте и карточках. Планета текущего дня крупная в центре; шесть остальных окружают её. Это художественная композиция, не схема Солнечной системы и не астрономический масштаб. Изображения — WebP нашего домена; CSS отвечает за композицию, оформление и движение.

Авторское решение: короткое появление сцены, медленное парение центрального тела и соседей, приближение картинки в карточке при наведении. Без мерцания, частиц и быстрого вращения. Все эффекты — только при `prefers-reduced-motion: no-preference`; при reduced-motion — статичные изображения.

Сохраняются тексты, расчёт сегодняшнего дня по Москве, адреса и доступные имена ссылок. Общий блок «Планета дня» получает изображения только при явном включении на странице недели; остальные страницы сохраняют свой вид. На телефоне — без горизонтальной прокрутки, основные цели нажатия от 44 px, подписи от 14 px.

Генерация: встроенный `image_gen.imagegen`, отдельный запрос на каждое изображение, прозрачность сохранена. Промпты — `prompts/weekday-planets.json`. Публикуемые варианты — `apps/web/public/images/weekday/*-{160,384,768}.webp`; исходные PNG остаются в каталоге генератора и в код не подключены.
