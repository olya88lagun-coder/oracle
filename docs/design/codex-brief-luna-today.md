## Зачем

У сайта нет страницы, на которую хочется заходить каждый день. «Луна сегодня» меняется ежедневно, по ней есть живой спрос, и ей не нужен контакт посетителя. У главного конкурента (arcanika.com) такая страница сильная по содержанию, но вид у неё перегруженный. Нужно, чтобы наша выглядела **дороже и спокойнее**: Луна — единственный герой, как драгоценный предмет на тёмном камне, а не набор разноцветных плиток.

**Тон:** тихая ночная сцена из `visual-direction.md`: почти чёрный фон с тёплым бронзовым светом, светлая слоновая кость для освещённого, тонкая антиква в заголовках. **Нельзя:** блёстки, мерцающие звёзды, неон, «магические» шрифты, красный, картинки с чужих доменов.

## Что делает код (не трогать)

- Расчёт по Москве на настоящих астрономических данных; диск Луны рисуется SVG по точной фазе (освещённая часть — готовый путь `path.moon-disc__lit`, терминатор уже верный).
- Показывает: фазу и освещённость, знак Луны, лунные сутки (по восходу Луны), восход и заход, ближайшую смену фазы, ленту из 14 дней с правильными фазами, описание дня (три блока, показываются только после приёмки текстов владелицей — вёрстка должна нормально выглядеть и без них), ссылки, вопросы и ответы, дисклеймер.
- Диск целиком `aria-hidden`: те же сведения есть текстом в плитках и подписи.

## Что довести

1. **Диск Луны — главный герой.** Крупный (десктоп 360–440 px, телефон ~280 px), освещённая часть — тёплая слоновая кость с мягким градиентом и едва заметной текстурой через CSS (без картинок), неосвещённая — глубокий тёмный с намёком на пепельный свет, тонкая бронзово-золотая кромка, мягкое свечение вокруг (`drop-shadow`, не тяжёлые фильтры). Кольцо делений вокруг диска: восемь точек, текущая теплеет.
2. **Плитки.** Четыре плитки спокойные, с тонкой рамкой и крупным значением: на десктопе четыре в ряд или две на две рядом с диском, на телефоне две колонки; подпись не мельче 14 px, значения читаемые; знак зодиака можно оформить глифом как в натальной карте (стили `natal-*` не менять, только брать идеи).
3. **Лента из 14 дней.** Горизонтальная лента с прокруткой по оси X **внутри блока** (страница горизонтально не прокручивается), на десктопе все 14 видны, сегодняшний выделен кольцом. Мини-диски — те же цвета, что у большого.
4. **Описание дня.** Три блока в колонке или сетке, вопрос для себя выделен (`.moon-text__question`), заголовки тонкой антиквой.
5. **Ссылки и вопросы** оформить как на соседних страницах (`.compat-faq`, `.numerology-more`), не изобретая нового.
6. **Движение** — только в `@media (prefers-reduced-motion: no-preference)`: «дыхание» диска (масштаб ±0,6 %, ~10 с), плавное проявление освещённой части при загрузке (~900 мс, `opacity`), мягкое свечение текущей отметки на кольце. Ничего не мерцает и не крутится; при «меньше движения» всё статично.
7. **Раскладка.** Десктоп (от 900 px): слева текст и плитки, справа диск, либо диск по центру с плитками под ним — как лучше смотрится; телефон: заголовок, диск, плитки в две колонки, дальше лента. Первый экран на 390×740 при открытой cookie-панели: видны заголовок и верхняя часть диска.
8. **Проверка:** 375 px без горизонтальной прокрутки страницы, контраст текста не ниже WCAG AA, зоны нажатия (ссылки, `summary`) не меньше 44 px, фокус с клавиатуры виден.

## Ограничения

- Не добавлять внешние шрифты, изображения и скрипты; не менять `.matrix-*`, `.natal-*`, `.wheel-*` стили; цвета — только переменные из `:root`, новые добавлять там же.
- Не менять тексты и разметку; не добавлять оценки «хороший день» и подобные подписи — их на странице нет сознательно.
