## Статус

Рабочие изменения — только `apps/web/src/app/globals.css`. Эта папка содержит визуальные доказательства и сверку. TSX, строки, логика, зависимости и production-флаги не менялись. `PAID_NATAL=on` использован только в игнорируемом локальном env; тестовая оплата `PAYMENTS=fake`, отдельная БД 5436, воркер `ai=none`.

**Продажа, образец, готовый разбор и печать оформлены в действующей разметке. Ожидание и карточка в портрете ждут двух CSS-зацепок.** Классы для них в CSS подготовлены; скриншоты `*-proposed-hook.png` показывают только DOM-превью, а `*-live.png` — текущую разметку приложения. Превью не является подтверждением интеграции.

Нужны отдельной правкой владельца разметки:

1. `ReportWaiting.tsx`: добавлять `report-waiting--natal` корневому section только для `product === "natal_report"`.
2. `portret/page.tsx`: добавлять `portrait-report--natal` элементу li только для `report.product === "natal_report"`.

Пока классов нет, изменять общий `.report-waiting` или угадывать тип по числу 9 нельзя: матрица использует тот же декор. У строки списка оба продукта имеют одни классы и одинаковую структуру.
