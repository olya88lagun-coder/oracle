# Натальная карта — визуальный этап 1–2

Локальные визуальные материалы для согласования. Репозиторий и работающий сайт не изменены.

Исходное ТЗ: `docs/design/codex-brief-natal.md`, коммит `31981ab359c7720b46fa9fa9054ee9eec70b48c3` ветки `master` репозитория `olya88lagun-coder/oracle`. Учтены Плацидус, линии по куспидам, обновлённые дома образца и два режима времени. Последняя правка: без времени исключены аспекты Луны. Данные взяты из ТЗ; эфемериды и дома здесь не рассчитываются.

## Просмотр

- `board.html` — оба колеса и полный набор глифов на одной доске.
- `index.html` — подробное превью, проверка глифов при 14/28 px, таблица данных, мобильная версия и сравнение с точными исходными образцами соседних практик.
- `preview-board-1280.png` — браузерный снимок общей доски.
- `preview-glyphs-1280.png` — браузерный снимок проверки глифов.
- `preview-wheel-1280.png`, `preview-wheel-375.png`, `preview-no-time-375.png` — снимки вариантов.

HTML открывается локально и не требует интернета. Шрифты Manrope и Noto Serif Display взяты из этого же репозитория, лежат в `assets/`; лицензии OFL приложены. Не заменять исходную картинку карточки натальной карты.

## SVG для передачи Claude

1. `natal-glyphs.svg`: 24 собственных символа, `viewBox="0 0 24 24"`, цвет `currentColor`, одинаковая толщина 1,6, закруглённые окончания. Файл является спрайтом; сам по себе при открытии показывает пустой холст. Глифы видны на страницах превью.
2. `natal-wheel.svg`: автономное колесо образца с временем, AC слева, 12 линий по предоставленным куспидам, 14 аспектов, таблица образца в HTML.
3. `natal-wheel-no-time.svg`: тот же набор позиций из ТЗ, Овен слева, без AC, MC и домов, метка неопределённости возле Луны. Показаны 11 аспектов: исключены Луна–Марс, Луна–Венера и Луна–Сатурн. Возле колеса и под списком аспектов добавлено «Аспекты Луны без времени рождения не считаются.»

В комментарии каждого колеса заданы радиусы, размеры, типы штрихов, цвета и углы размещения смещённых меток. Все истинные положения сохранены отдельно от положений подписей. `visual-contract.json` содержит данные визуального образца и параметры оформления.

**Число глифов:** заголовок ТЗ говорит о 25, но список содержит 11 тел/точек + 12 знаков + 1 знак обратного движения = 24. Созданы все перечисленные идентификаторы. Дополнительный символ без согласования не придуман.

**Мобильное упрощение:** градусы скрыты на колесе при узком экране и полностью доступны в таблице подробного превью. Числа домов и обозначения осей остаются не мельче 11 px в проверенном мобильном виде. При ширине SVG 343 px их размер — 12,39 px.

**Дома:** линии получают переданные куспиды. Внешнее кольцо знаков имеет равные 30-градусные секторы; внутренние дома — разную ширину. Границы знаков не используются вместо куспид. Тонкие продолжения четырёх осей дополняют 12 основных линий. Система Порфирия использует те же зацепки для стилей и другую подпись; данные такого отдельного образца в этом этапе не подставлялись.

**Скученные точки:** подписи раздвинуты минимум на 10°, порядок сохранён; выноски ведут к исходной долготе. Подписи градусов ориентированы радиально для читаемости при тесной группе.

**Аспекты:** соединение — кружок без хорды; секстиль — пунктир; квадрат — средняя сплошная; трин — тонкая сплошная; оппозиция — толстая сплошная. Цвет не единственный признак. Квадрат в карте-образце отсутствует, его стиль показан в легенде.

## Проверка

- XML трёх SVG разобран без ошибок.
- Все 24 идентификатора уникальны, имеют русские `<title>` и разрешаемые ссылки `<use>`.
- Позиции и куспиды соответствуют предоставленным числам образца; расчётные формулы продукта не проверяются и не изменяются этим этапом.
- Превью просмотрено в браузере при viewport 375 и 1280 px; горизонтального переполнения нет.
- В мобильной проверке доступная ширина документа — 360 px из-за полосы прокрутки; ширина SVG — 326 px. Минимальный видимый шрифт SVG — 11,77 px.
- Текстовые контрасты используемых цветов выше 4,5:1; результаты — `qa-summary.json`.
- В подробном превью ссылки имеют зоны не ниже 44 px; одна H1; повреждённых изображений и внешних ресурсов нет.
- Вариант без времени не содержит линий/номеров домов или AC/MC.
- В варианте без времени 11 аспектов и 11 строк списка; три аспекта Луны исключены. Точное пояснение присутствует возле колеса и под списком.
- Контрольные SHA256 подтвердили, что SVG-глифы и колесо с временем не изменились при этой правке.

Это проверка статического оформления. Рабочий калькулятор, поиск городов, сервер, портрет, оплата и SEO не реализованы.
