# Бриф для Codex — макеты платного разбора матрицы (план 2б)

Текст ниже целиком вставляется в Codex. Результат — картинки-макеты, **не код**: код по ним собирает Claude.

---

Нарисуй макеты новых экранов сайта «Твой оракул» (https://tvoy-orakul.ru) для платного разбора «Матрицы судьбы». Репозиторий — этот, ветка `feat/matrix-paid`.

**Прочитай перед работой:**
- `docs/design/wireframes/matrix-paid.html` — каркас: что где стоит, состояния, требования (жёлтые заметки). Раскладку и состав бери отсюда.
- `docs/design/visual-direction.md` — визуальная система сайта: тёмная сцена, бронза и лаванда, антиква в заголовках, токены цветов.
- `docs/design/mockups/matrix-*.webp` — утверждённые макеты бесплатной матрицы. Новые экраны должны выглядеть как продолжение этих, а не как отдельный сайт.
- `apps/web/public/arcana/11-sila.webp` — иллюстрация аркана центра для примера (на всех экранах пример — дата 18.11.1988, центр 11 Сила).

**Что нарисовать** — каждый экран в двух ширинах, компьютер 1440 px и телефон 375 px:

1. `matrix-paid-offer` — блок продажи «Разбор всей матрицы — 290 ₽» под бесплатным результатом на `/matrica-sudby`: оглавление семи глав с арканами, пример абзаца, поле «E-mail для чека», кнопка. На телефоне — версия для гостя с кнопкой «Войти и купить разбор». Покажи кусок бесплатного результата выше, чтобы было видно соседство.
2. `matrix-paid-waiting` — три состояния страницы после оплаты: «Ждём подтверждения оплаты», «Готовим разбор», «Оплата не прошла». Можно одной картинкой на ширину, три состояния рядом.
3. `matrix-paid-report` — готовый разбор: обложка (иллюстрация аркана центра, «Ваш центр — Сила», дата, оглавление), глава 1 с метками арканов и абзацами, глава 7 «Ваш сценарий» с семью именованными блоками, дисклеймер внизу. Это длинное чтение — главное, чтобы текст удобно читался на телефоне.
4. `matrix-paid-portrait` — карточка «Разборы» в «Моём портрете» (две строки: готовый разбор и «готовится») и подвал с новой ссылкой «Оферта».

Сохрани как `docs/design/mockups/matrix-paid-<экран>-1440.webp` и `…-375.webp`.

**Обязательно:**
- Тексты кнопок и полей — дословно: «Разбор всей матрицы — 290 ₽», «Войти и купить разбор», «Купить разбор — 290 ₽», «Открыть разбор», «Попробовать снова», «E-mail для чека», «Оферта». Остальные тексты бери из каркаса, новых фраз, цитат и пунктов меню не добавляй.
- Платный блок спокойный: без таймеров, «осталось N мест», ярких плашек и всплывающих окон; он не крупнее и не ярче бесплатного результата.
- Текст не меньше 14 px, текст разбора — не меньше 16 px; кнопки и ссылки от 44 px в высоту; контраст WCAG AA; на 375 px ничего не выходит за край.
- Только иллюстрации арканов из `apps/web/public/arcana/` и существующие картинки сайта; новых картинок не генерируй. Без блёсток, свечей, неона — см. «Нельзя» в `visual-direction.md`.
- Код и файлы вне `docs/design/mockups/` не трогай.
