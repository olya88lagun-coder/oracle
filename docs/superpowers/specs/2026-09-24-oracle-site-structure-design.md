# ORACLE — структура сайта, путь пользователя и порядок запуска

Дата: 2026-09-24
Статус: согласовано 2026-09-24

## 1. Зачем этот документ

ORACLE v0.9 (папка `oracle_mvp_v09`) подтвердил тон и методику, но как основа для роста не годится: один HTML-файл, сессии в памяти, нет базы, оплаты и защиты API, «Лила» собрана из выдуманных клеток, астроразбор не считает карту. Этот документ фиксирует, каким ORACLE должен стать: какие практики, как устроен сайт, как человек в него входит и за что платит, в каком порядке всё строим.

Контекст спроса: по Wordstat запросы на эзотерику примерно в 4 раза выше, чем на психологические тесты. Спрос сосредоточен вокруг конкретных бесплатных инструментов («матрица судьбы по дате рождения», «натальная карта онлайн», «таро расклад онлайн», «совместимость по дате рождения», значения арканов и карт).

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Подача | **Язык эзотерики, суть рефлексии.** Настоящие расчёты и символы; трактовка — «что это говорит обо мне сейчас». Не обещаем будущего, не пугаем, не создаём зависимость. |
| Практики | Матрица судьбы / нумерология, Таро, Натальная карта + совместимость, Лила. Закладываем все, запускаем по очереди. |
| Монетизация | **Сначала разовые покупки, подписка PRO — позже**, когда появится ради чего возвращаться. |
| Каналы | **Поиск (SEO-справочник) + шеринг** и **платная реклама** (Яндекс.Директ, VK Реклама). |
| Архитектура сайта | **Гибрид:** отдельный вход под каждую практику + общий личный профиль «Мой портрет». |
| Репозиторий | Новый: `C:\dev\oracle`. v0.9 остаётся резервом, из него переносим промпт, схемы ответов и визуальный стиль. |

## 3. Карта сайта

```
/                          Главная: входы в практики + «Мой портрет» + карта дня
│
├─ /matrica-sudby          Калькулятор (только дата) → результат на той же странице
│   └─ /arkan-1 … /arkan-22           Справочник арканов (SEO)
├─ /lila                   Игра с намерением
│   └─ /kletki/<slug>  (72)           Справочник клеток (SEO, см. §7)
├─ /taro                   Расклад на вопрос
│   ├─ /karta-dnya                    Карта дня
│   └─ /karty/<slug>  (78)            Значения карт (SEO)
├─ /sovmestimost           Две даты → совместимость + приглашение партнёру
│   └─ /<znak>-i-<znak>  (78)         Пары знаков (SEO)
├─ /natalnaya-karta        Калькулятор (дата + время + город)
│   └─ /<planeta>-v-<znake>  (120)    Планета в знаке (SEO)
│
├─ /portret                Личное пространство: расчёты, покупки, история, игры
├─ /pro                    Позже
└─ /privacy /oferta /cookies
```

Правила:
- Каждый калькулятор — одновременно посадочная для рекламы: поле ввода на первом экране, без регистрации.
- Справочник (~370 страниц) — вход из поиска; каждая страница ведёт в соответствующий калькулятор.
- Дата рождения вводится один раз и переиспользуется всеми практиками (сначала в браузере, после входа — в профиле).

## 4. Путь пользователя

Пример: пришла из рекламы по «матрица судьбы».

1. **Вход.** Вводит дату → результат за ~20 секунд.
2. **Бесплатный результат, ценный сам по себе:** полная диаграмма матрицы со всеми числами (расчёт не прячем), трактовка 3 ключевых точек, одно действие на сегодня и вопрос для себя (методика ORACLE).
3. **Одно платное предложение ниже результата:** «Разбор всей матрицы — 290 ₽», с честным перечнем того, что внутри.
4. **Одна связка с другой практикой:** «Твоя дата уже есть — добавь время рождения, откроется натальная карта» / «Сыграй Лилу со своим вопросом».
5. **Сохранение:** «Сохранить в портрет» → вход через VK. Предлагаем, не требуем.
6. **Возвращение:** карта дня; прогресс «портрет собран на 2 из 4»; приглашение на совместимость приводит второго человека.
7. **Главная покупка:** после двух открытых практик появляется «Полный портрет» — сведение практик в одну картину.

### Правила «ненавязчиво»

- Не больше одного платного блока на странице; никаких всплывающих окон с оплатой.
- Никаких таймеров, «осталось N мест», запугивания и формулировок «без этого тебя ждёт…».
- Бесплатный результат выглядит законченным, а не обрезанным на полуслове.
- Обращение не зависит от пола (нейтральные формулировки) или пол выбирается один раз.

## 5. Монетизация

Цены — гипотезы для проверки, не окончательные.

| Продукт | Цена | Когда появляется |
|---|---|---|
| Разбор одной практики (матрица, таро-расклад, натальная карта, совместимость) | 190–290 ₽ | с запуском практики |
| Сессия Лилы с проводником ORACLE и итоговым выводом | 290 ₽ | этап 2 |
| «Полный портрет» — сведение нескольких практик | 790 ₽ | этап 6, когда открыто ≥2 практики |
| ORACLE PRO — карта дня с трактовкой по профилю, месяц в транзитах, сохранённые игры, диалог без лимита | ~399 ₽/мес | этап 6 |

**Экономика бесплатного уровня.** Бесплатный результат собирается из заранее написанных и отредактированных текстов, а не генерируется AI на каждый визит. Рекламный посетитель ничего не стоит, качество под контролем. AI (GigaChat) работает только в платном: персональный разбор, проводник Лилы, сведение практик.

## 6. Порядок запуска

**Этап 0 — Фундамент.**
- Проект на стеке Граней: Postgres, ЮKassa, воркер, юридические страницы, деплой на VPS; добавить вход через VK.
- LLM — GigaChat (доступен в РФ, данные не уходят за границу; 152-ФЗ).
- Защита API: ограничение частоты, серверная проверка оплаты перед платной генерацией, ограничение длины истории диалога, без утечки текстов ошибок провайдера.
- Метрика с целями воронки, отдельный домен.
- Параллельно: проверить правила модерации эзотерики в Директе и VK Рекламе до выделения бюджета.

**Этап 1 — Матрица судьбы.** Калькулятор, бесплатный результат, платный разбор 290 ₽, 22 страницы арканов, базовый «Мой портрет». Затем тест рекламы небольшим бюджетом: цена клика, доля «бесплатный результат → покупка». Решение о масштабировании — только по этим цифрам.

**Этап 2 — Лила.** Источник 72 клеток есть (`content/lila/cells-source.md`). Бесплатно — полноценная игра: намерение, кубик, змеи и стрелы, собственные тексты клеток и вопросы по смыслу источника (см. §7), история ходов. Платно — сессия с проводником ORACLE: связь каждого хода с намерением и итоговый вывод.

**Этап 3 — Таро и карта дня.** Сюда переезжает «Новый вопрос» из v0.9 (расклад на вопрос). Колода: Райдер–Уэйт в оригинальных иллюстрациях Памелы Колман Смит (общественное достояние) или собственная колода в фирменном стиле — решить на этапе.

**Этап 4 — Совместимость.** Сначала по двум датам через матрицу (расчёт уже есть), приглашение партнёру, страницы пар знаков.

**Этап 5 — Натальная карта.** Эфемериды — `astronomy-engine` (MIT); Swiss Ephemeris не берём из-за AGPL/платной лицензии. Нужны геокодинг города и историческая база часовых поясов (в РФ пояса многократно менялись). После — синастрия в совместимости.

**Этап 6 — «Полный портрет» и PRO** с автоплатежами ЮKassa.

**Не делаем в первой версии:** PRO, Telegram-бот, свободный чат без лимита, блог, мобильное приложение.

## 7. Лила: источник и решения

- **Названия и смысл** клеток берутся **только** из `content/lila/cells-source.md` (72 клетки: название, «О чём это», «О чём задуматься») — ничего не придумываем и смысл не искажаем.
- **Формулировки — собственные (утверждено 2026-09-24).** Файл-источник — пересказ со стороннего сайта (Дзен), поэтому его текст не публикуется ни в игре, ни в справочнике: это чужой текст и неуникальный контент для Яндекса. Для каждой клетки пишем свои «О чём это» и «О чём задуматься» в тоне ORACLE (язык гипотез, нейтральный род), сверяя смысл с источником. Черновик готовит Claude, финальную вычитку делает владелец проекта. Работа входит в этап 2.
- **Змеи и стрелы — классическая схема Хариша Джохари (утверждено 2026-09-24):**
  - змеи: 12→8, 16→4, 24→7, 29→6, 44→9, 52→35, 55→3, 61→13, 63→2, 72→51;
  - стрелы: 10→23, 17→69, 20→32, 22→60, 27→41, 28→50, 37→66, 45→67, 46→62, 54→68.
- **Язык (утверждено 2026-09-24).** Формы рода в вопросах выравниваются по одному правилу; смысл клеток не меняется.

## 8. Что переносим из v0.9

- Системный промпт и методику из 8 шагов (вопрос → паттерн → напряжение → ресурс → слепая зона → точка изменения → эксперимент → следующий вопрос).
- Подход «ответ LLM строго по JSON-схеме + проверка полей».
- Визуальный язык: тёмный премиальный интерфейс без ярмарочной эзотерики (с доработкой иерархии — экран Deep Dive в v0.9 перегружен однотипными карточками).

## 9. Метрики успеха этапа 1

- Доля посетителей калькулятора, получивших бесплатный результат.
- Конверсия «бесплатный результат → покупка разбора».
- Стоимость привлечения покупателя из рекламы против цены разбора.
- Доля сохранивших портрет (вход через VK) и вернувшихся в течение 7 дней.

Целевые значения фиксируются после первых данных, а не заранее.
