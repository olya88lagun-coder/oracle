## 2. Расчёт (`packages/core/src/matrix.ts`)

Схема Натальи Ладини, числа 1–22. Свёртка `reduce(n)`: пока `n > 22`, заменить `n` суммой его цифр.

| Точка | Формула | Роль |
|---|---|---|
| A | `reduce(день)` | личность (трактуется) |
| B | `reduce(месяц)` | верх |
| C | `reduce(сумма цифр года)` | право |
| D | `reduce(A+B+C)` | задача (трактуется) |
| E | `reduce(A+B+C+D)` | центр (трактуется) |
| F, G, H, I | `reduce(A+B)`, `reduce(B+C)`, `reduce(C+D)`, `reduce(D+A)` | родовой квадрат |
| A2, B2, C2, D2 | `reduce(X+E)` для X ∈ {A,B,C,D} | внутренние точки основного квадрата |
| A1, B1, C1, D1 | `reduce(X+X2)` | внешние внутренние точки |
| F2…I2, F1…I1 | те же правила для диагоналей | внутренние точки родового квадрата |
| X (сердце) | `reduce(C2+D2)` | линия отношений и денег |
| love, money | `reduce(X+D2)`, `reduce(X+C2)` | точки любви и денег |
| sky, earth, personal | `reduce(B+D)`, `reduce(A+C)`, `reduce(sky+earth)` | личное предназначение |
| male, female, social | `reduce(F+H)`, `reduce(G+I)`, `reduce(male+female)` | социальное предназначение |
| spiritual, planetary | `reduce(personal+social)`, `reduce(social+spiritual)` | духовное и планетарное |

API: `calculateMatrix(birthDate: BirthDate): Matrix` — объект с именованными точками (`number` 1–22). Вход — уже проверенная `BirthDate` из `parseBirthDate`.

Пример: 18.11.1988 → A 18, B 11, C 8, D 10, E 11.

Не делаем: таблицу чакр, прогноз по годам (предсказание — вне тона сайта).

## 3. Контент (`packages/content`)

Новый пакет. `arcana/NN-slug.md` × 22 → сборка в типизированный JSON (как статьи Граней).

Шапка: `number`, `name`, `slug`, `keywords` (3–4). Секции (все обязательны):
- `Суть` — 2–3 абзаца, язык гипотез;
- `В личности` — для точки A;
- `В центре` — для точки E;
- `Как задача` — для точки D, урок и точка роста;
- `В ресурсе` и `В перекосе` — по 3 пункта;
- `Действие на сегодня` — одно маленькое дело;
- `Вопрос для себя` — один вопрос в методике ORACLE.

Проверка при сборке падает, если: файлов не 22; номера не 1…22 без пропусков; нет секции; найдено слово из стоп-списка (`вас ждёт`, `вам суждено`, `карма накажет`, `порча`, `сглаз`, `гарантирует` и т. п.).

Правила текста: нейтральный род, обращение на «вы», без предсказаний и диагнозов.

Арканы и адреса (`/matrica-sudby/arkan-N-slug`): 1 Маг `mag` · 2 Верховная Жрица `verkhovnaya-zhrica` · 3 Императрица `imperatrica` · 4 Император `imperator` · 5 Иерофант `ierofant` · 6 Влюблённые `vlyublennye` · 7 Колесница `kolesnica` · 8 Справедливость `spravedlivost` · 9 Отшельник `otshelnik` · 10 Колесо Фортуны `koleso-fortuny` · 11 Сила `sila` · 12 Повешенный `poveshennyj` · 13 Смерть `smert` · 14 Умеренность `umerennost` · 15 Дьявол `dyavol` · 16 Башня `bashnya` · 17 Звезда `zvezda` · 18 Луна `luna` · 19 Солнце `solnce` · 20 Суд `sud` · 21 Мир `mir` · 22 Шут `shut`.

## 4. Экраны

**`/matrica-sudby`** — калькулятор и результат на одной странице (индексируется):
1. Первый экран: заголовок, пояснение, поле «Дата рождения», кнопка «Рассчитать». Поле заполнено, если дата есть в браузере или в портрете.
2. Результат (появляется ниже, страница прокручивается к нему):
   - диаграмма-восьмиугольник (SVG) со всеми числами, A/E/D подсвечены; для скринридеров — таблица точек;
   - три карточки «Личность», «Центр», «Задача»: номер и название аркана, текст позиции, ссылка на страницу аркана;
   - «Действие на сегодня» и «Вопрос для себя» — по аркану центра;
   - предназначения: личное, социальное, духовное — число, название, ссылка;
   - «Сохранить в портрет» (без входа) или «Дата сохранена в портрете» (со входом);
   - «Поделиться» — ссылка на страницу аркана центра (Web Share API, иначе копирование ссылки);
   - одна связка: «Скоро — Лила: игра с вашим вопросом».
   Платного блока в 2а нет.

**`/matrica-sudby/arkan-N-slug`** × 22 — статические страницы: крупный номер, название, ключевые слова, все секции, соседние арканы, кнопка «Рассчитать свою матрицу». Индексируются, разметка `Article`.

**Главная:** карточка «Матрица судьбы» — ссылка на калькулятор, метка «Открыто» вместо «Скоро».

**`/portret`:** при сохранённой дате карточка матрицы показывает три аркана (личность, центр, задача) и ведёт на калькулятор.

Каркасный макет: `docs/design/wireframes/matrix.html`. Визуал — в текущей системе (`docs/design/visual-direction.md`), прорисовывает Codex.

## 5. Дата: браузер → портрет

- Без входа: после «Рассчитать» дата — только в `localStorage` (`oracle-birth-date`), на сервер не отправляется.
- «Сохранить в портрет» → `/login?next=/matrica-sudby`. `next` принимается только из белого списка внутренних путей; путь возврата передаётся через подписанный state-токен VK. После входа — возврат на калькулятор, страница сохраняет дату через `/api/profile/birth-date`.
- Если в портрете другая дата — главной считается портрет; браузерная копия обновляется. Портрет без спроса не перезаписывается.
- Выход и «Удалить мои данные» стирают `oracle-birth-date`.
- Политика: добавить «Калькулятор считает в вашем браузере; дату рождения мы получаем, только когда вы сохраняете её в портрет». Редакция политики `2026-10-v1`; согласие не меняется.

## 6. Аналитика, ошибки, SEO

- Цели Метрики (после согласия на cookie): `matrix_calculated`, `matrix_save_click`, `matrix_share`, `arcana_to_calculator`.
- Неверная дата — сообщение в `role="alert"` (проверка из `packages/core`). Сбой сохранения после входа — сообщение и «Повторить», результат остаётся.
- `sitemap.xml`: калькулятор + 22 аркана. Свои title/description, canonical.

## 7. Тесты

- `packages/core`: матрица — таблица известных дат (сверка с 2–3 популярными калькуляторами), 29 февраля, 31-е, 1900 и текущий год, свойство «все точки 1–22» на всех датах 1900…сегодня; покрытие 100 %.
- `packages/content`: проверка сборки (22 файла, секции, стоп-список).
- `apps/web`: безопасный `next`.
- e2e: расчёт без входа → A/E/D; перезагрузка → дата на месте; «Сохранить в портрет» → вход → возврат → дата в портрете; главная → калькулятор; страница аркана индексируется и ведёт на калькулятор; неверная дата → ошибка; после удаления данных браузерная копия стёрта.
