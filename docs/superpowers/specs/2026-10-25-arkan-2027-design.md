# Мой аркан 2027 года

Статус: пользователь согласовал вариант с центром и точную формулу 25.10.2026. Разрешена локальная реализация с проверками. Продакшен и слияние не разрешены.

## Найденная структура

- Next.js App Router: `apps/web/src/app`; React-компоненты: `apps/web/src/components`.
- `packages/core/src/matrix.ts`: `calculateMatrix`, центр `E`, `reduceToArcanum`. Годовой формулы до этой задачи нет.
- `packages/content/arcana`, `arcanumByNumber`: 22 готовых интерпретации; `public/arcana`: существующие изображения.
- `lib/seo.ts`, `app/sitemap.ts`: метаданные и карта сайта; `lib/analytics.ts`: цели и фильтр UTM, согласие контролируется существующей Analytics.
- `MatrixCalculator`, `ReportOffer`: существующий путь к полному разбору, цена из `MATRIX_REPORT_PRICE_KOPECKS` (390 ₽).

## Метод и варианты

Единого определения личного аркана года нет. https://matrica-sudby22.ru/blog/matrica-sudby/matrica-sudby-po-godam/ описывает свёрнутый день + месяц + сумму цифр года. https://iiset.io/blog/arkan-goda-kak-rasschitat описывает центр матрицы + свёртку полного дня, месяца и суммы цифр года. https://arkani-taro.ru/gadanie-taro-online/arkan-goda/ использует сумму цифр и вычитание 22. Источники прочитаны 25.10.2026; это описания практик, не научная валидация.

Пользователь выбрал второй вариант: `R(E + R(day + month + 11))`, где `E = calculateMatrix(birthDate).E`, `R = reduceToArcanum`. День берётся целиком. Промежуточную сумму дня и месяца не сворачиваем. 11 = 2 + 0 + 2 + 7. Период: 01.01–31.12.2027. Число 22 сохраняем; 8 — Справедливость, 11 — Сила.

Контроль: 14.03.1992: E=13; 14+3+11=28 → 10; 13+10=23 → 5. 29.11.1990: E=10; 29+11+11=51 → 6; 10+6=16. Вариант без центра отклонён пользователем.

## ТЗ

Страница `/arkan-2027`: один H1, доступная форма даты, расчёт в браузере, явная арифметика, смысл аркана, ресурсы, ловушки, отношения, дело, самореализация, вопрос и три практических совета. Существующие тексты подаются как символы для размышления о годе, без обещаний событий. Первый совет — существующее действие аркана; ещё два — редакционные упражнения для недели и планов на год, отдельные для каждого из 22 арканов. Карточка 1080×1350 PNG без даты рождения, сохранение и системная отправка с запасным копированием ссылки. Явная ссылка VK открывает форму отправки текста и публичной ссылки; для картинки пользователь прикрепляет PNG. Telegram исключён по прямому запросу пользователя.

Уточнение стратегии от пользователя 25.10.2026: новогодний калькулятор — бесплатный инструмент привлечения аудитории, а не самостоятельный платный прогноз. Бесплатный результат должен быть достаточно содержательным. Существующий полный разбор Матрицы остаётся 390 ₽; помесячные предсказания и ключевые даты не добавляются.

Стиль: существующие Noto Serif Display / Manrope, ночной фон, бронзовые рамки, существующие изображения. Приоритет 375 px, элементы ≥44 px, текст ≥14 px, видимый фокус, reduced motion.

CTA ведёт к существующей Матрице и предложению полного разбора за 390 ₽. Дата передаётся только по явному нажатию через sessionStorage, однократно; профиль, оплата, доступ и юридические тексты не меняются. При недоступном хранилище переход работает, дату можно ввести заново.

SEO: title, description, canonical, OG, FAQPage из тех же вопросов, sitemap и ссылка из раздела Матрицы. UTM только у ссылки, которой делятся наружу, чтобы внутренний переход не перезаписывал рекламную кампанию. Существующий фильтр входящих UTM сохраняется.

Цели: `year_arcana_calculated`, `year_arcana_save`, `year_arcana_share`, `year_arcana_offer_view`, `year_arcana_to_matrix`, `year_arcana_vk`. Последняя считает открытие формы VK, не факт публикации. События не содержат дату, имя, профиль или полный адрес. Согласие и готовность счётчика — действующие механизмы проекта. Создание целей в кабинете Метрики отдельно; здесь только код.
