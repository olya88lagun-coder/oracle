**Goal:** Mobile seasonal entry point with free interpretation and the existing Matrix funnel.
**Architecture:** Pure calculation in core, existing content and images, isolated page/components, existing consent-aware analytics. No new backend or payment product.
**Tech Stack:** Next.js 16, React 19, TypeScript, Canvas, Vitest.
**Spec:** `docs/superpowers/specs/2026-10-25-arkan-2027-design.md`.

## Global Constraints

- Formula: `R(E + R(day + month + 11))`, approved 25.10.2026.
- No production changes, personal data in URLs/events, external dependencies or payment changes.
- 375 px, controls ≥44 px, text ≥14 px; existing tokens and imagery.

- FAQ, canonical, sitemap and visible methodology must agree.
