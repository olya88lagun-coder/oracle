# Первая партия исправлений по поисковому аудиту

## Задача и границы

22 ноября владелица поручила начать работу по трём приоритетам аудита Яндекс Вебмастера: натальная карта, малоценные страницы, поисковая посадочная Лилы. Этот PR — первая проверяемая партия, а не обещание вернуть страницы в индекс.

Основа: свежий `origin/master` c4a330f. Только tvoy-orakul.ru. Публикация — через PR; master мержит владелица.

## Решение

Сначала улучшить существующие продуктовые страницы и пути между ними. Массовое увеличение объёма 29 страниц без проверки их содержания не обосновано. Смена canonical и снятие noindex тоже не обоснованы: у натальной карты canonical корректный, а `/lila/igra` содержит личную партию.

1. Дать на `/natalnaya-karta` открытый учебный пример, который виден в серверном HTML без расчёта и без регистрации. Использовать условный момент того же примера, что `/natalnaya-karta/primer`: Москва, 7 марта 1990, 12:25. Положения вычислять существующим ядром, а не вписывать вручную. Отделить учебный пример от результата посетителя. Пояснить порядок чтения, дать ссылки на значения и методику. Существующие H1, форму, FAQ, метаданные и сохранение оставить.
2. На исключённой `/taro/karta-dnya` добавить разбор использования одной конкретной карты: наблюдаемая ситуация, посильное действие, вечерний вопрос. Не подменять случайно выбранную пользователем карту.
3. Со страниц клеток Лилы дать осмысленную ссылку на правила и поле `/lila#how`, сохранив прямую кнопку начала партии. Добавить подходящие контекстные ссылки из статей о Лиле, если их там нет.
4. Зафиксировать подтверждённые исключения и дальнейший порядок работы в `docs/seo/`. Указать задержки отчётов и дату последнего обхода, не называть доступность индексации фактом нахождения в поиске.

## Проверки

- [x] Проверить учебные положения по тому же моменту через существующую цепочку расчёта города и часового пояса; проверить открытый серверный HTML.
- [x] Выполнить `pnpm typecheck` и `pnpm test`, исправить связанные регрессии.
- [x] Собрать web; проверить исходный HTML нужных URL, canonical/robots, единственный H1, ссылки.
- [x] Посмотреть новые блоки на телефоне и десктопе, проверить отсутствие горизонтальной прокрутки.
- [ ] Просмотреть итоговый diff, создать PR и проверить CI.

После мержа: проверить live HTML и точечно отправить изменённые важные URL на переобход. До выкладки переобход не нужен. Включение в поиск проверяется отдельно после нового обхода; смена статуса не гарантирована.

## Результаты локальной проверки

- `pnpm typecheck`: успешно.
- `pnpm exec vitest run --maxWorkers=2`: 322 файла, 2678 тестов — успешно.
- `pnpm exec next build --webpack` с локальными тестовыми переменными: успешно. Turbopack в песочнице Windows не смог создать служебную junction-ссылку; конфигурация проекта не менялась.
- Семь URL (`/natalnaya-karta`, `/taro/karta-dnya`, `/lila`, `/lila/igra`, клетка 1, две статьи о Лиле): HTTP 200, по одному H1. У поисковых страниц свой canonical и `index, follow`; у игры сохранён `noindex, nofollow`.
- Учебный блок есть в исходном ответе сервера. На 375 px у натальной карты и клетки горизонтального выхода нет; на 1280 px пример расположен в три колонки.
- На карте дня при мобильной проверке обнаружен выход длинного названия в существующем списке арканов: scrollWidth 369 при clientWidth 360. После переноса текста — 360 / 360. Добавлен отступ перед новым подзаголовком.
- Отдельное ревью кода: блокирующих замечаний нет. Точный список 29 исключений сверен на обеих страницах Вебмастера и сохранён в CSV.
