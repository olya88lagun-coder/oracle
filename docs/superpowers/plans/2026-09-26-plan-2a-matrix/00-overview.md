# План 2а — бесплатная «Матрица судьбы»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Задачи лежат в отдельных файлах `task-NN-*.md` этой папки; выполнять по порядку.

**Goal:** На tvoy-orakul.ru работает бесплатная «Матрица судьбы»: калькулятор `/matrica-sudby` считает матрицу в браузере и показывает полную диаграмму, трактовку трёх ключевых точек (личность, центр, задача), действие на сегодня, вопрос для себя и предназначения; 22 справочные страницы арканов; дата переносится в «Мой портрет» после входа; главная и портрет ведут в матрицу.

**Architecture:** Расчёт — чистая функция `calculateMatrix` в `packages/core`. Тексты арканов — Markdown-файлы в новом пакете `packages/content`, собираемые скриптом в `src/generated/arcana.json` и разбираемые/проверяемые в TypeScript (как контент Граней). Калькулятор — клиентский компонент: дата анонимного посетителя живёт только в `localStorage` (`oracle-birth-date`), на сервер уходит лишь при сохранении в портрет через существующий `POST /api/profile/birth-date`. Возврат после входа — параметр `next` из белого списка, который едет через подписанный state-токен VK. Страницы арканов — статические (`generateStaticParams`). Вся логика отображения, которую можно проверить без браузера, вынесена в `apps/web/src/lib/*.ts` с юнит-тестами; поведение страниц проверяют сквозные тесты Playwright.

**Tech Stack:** как в плане 1 — Node 24, pnpm 12, TypeScript 6, Next.js 16.3 (App Router), React 19.3, Vitest 5, Playwright 1.63. Новых npm-зависимостей нет.

**Spec:** `docs/superpowers/specs/2026-09-26-matrix-free-design.md` (все разделы). **Каркас экранов:** `docs/design/wireframes/matrix.html`. **Визуальная система:** `docs/design/visual-direction.md`. **Правила для агентов:** `AGENTS.md`. **Дорожная карта:** `docs/superpowers/plans/00-roadmap.md`.

- Числа арканов — **1…22**. Свёртка: пока `n > 22`, `n` = сумма цифр `n`.
- Ключевые точки бесплатного результата — ровно **A (личность), E (центр), D (задача)**. «Действие на сегодня» и «Вопрос для себя» — по аркану **центра (E)**.
- **Дата рождения анонимного посетителя не уходит на сервер** и никогда не попадает в адрес страницы, в параметры ссылок и в Метрику. Хранение в браузере — только ключ `localStorage` `oracle-birth-date` со значением `YYYY-MM-DD`, все обращения в `try/catch`.
- **Портрет главнее браузера:** если у вошедшего человека в портрете есть дата, калькулятор показывает её и переписывает `oracle-birth-date`; портрет без явного действия не перезаписывается.
- Возврат после входа — только пути из белого списка `SAFE_NEXT_PATHS = ["/portret", "/matrica-sudby"]`; всё остальное → `/portret`.
- Тексты интерфейса дословно (по ним пишутся e2e): «Дата рождения», «Рассчитать», «Войти и сохранить», «Сохранить в портрет», «Сохранено.», «Повторить», «Поделиться», «Рассчитать свою матрицу», метки практик «Открыто» и «Скоро». Обязательные тексты из `AGENTS.md` не меняются.
- Тон текстов: язык гипотез, обращение на «вы», нейтральный род, без предсказаний, диагнозов, «кармы» и запугивания. Стоп-слова проверяет сборка контента (задача 2).
- Цели Метрики плана 2а: `matrix_calculated`, `matrix_save_click`, `matrix_share`, `arcana_to_calculator` (плюс существующие `login`, `birth_date_saved`). Метрика — только после согласия на cookie (логика `Analytics.tsx` не меняется).
- Индексация: `/matrica-sudby` и 22 страницы `/matrica-sudby/arkan-N-slug` — `index, follow` через `publicMetadata`, в `sitemap.xml`. Личные страницы — как в плане 1.
- Доступность: текст не меньше 14 px, зоны нажатия от 44 px, контраст WCAG AA, видимый фокус, `prefers-reduced-motion`, без горизонтальной прокрутки на 375 px. Ошибки — `role="alert"`, успех — `role="status"`.
- Визуал — текущая система (`visual-direction.md`, классы `globals.css`). **Раскладка — по макетам Codex** `docs/design/mockups/matrix-*.webp` (утверждены владелицей 2026-09-26): на компьютере диаграмма слева, справа список позиций A–E и три ключевые карточки; «Действие на сегодня» и «Вопрос для себя» рядом; предназначения — три карточки; страница аркана на телефоне — секции раскрываются (`<details>`). Кнопка «Рассчитать» — лавандовая. Из макетов **не берём**: иллюстрации арканов (22 картинки — отдельный PR после 2а; в карточках — крупный номер и название), декоративные фразы и цитаты, которых нет в спецификации, пункты меню и подвала, которых нет на сайте. Числа на макетах — примерные; в коде всё считается. Тексты — только из спецификации, каркаса и файлов арканов.
- Тесты: Vitest (AAA), Playwright на локальном приложении. Покрытие `packages/*/src`, `apps/web/src/server`, `apps/web/src/lib` ≥ 80 %; `packages/core/src/matrix.ts` — 100 %.
